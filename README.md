# mistahub

A personal hub collecting small single-page apps — quizzes, games and tools —
all under one GitHub Pages project.

**Live:** https://mistahuman.github.io/mistahub/

## Stack

Astro · Svelte 5 · Skeleton · Tailwind · lucide-svelte

## Run

```bash
npm install
npm run dev      # -> http://localhost:4321/mistahub/
```
